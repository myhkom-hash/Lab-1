Репозиторій лабораторних робіт

Цей репозиторій містить вихідні коди та матеріали для виконання 5 лабораторних робіт.
Кожна робота знаходиться у відповідній ізольованій папці та містить усі необхідні файли
для запуску та тестування.

Структура репозиторію

Репозиторій розбитий на 5 основних директорій відповідно до тем курсу:

● lab-01: Фронтенд. Базова сторінка застосунку з HTML-формою, CSS та
відображенням даних за допомогою JavaScript (DOM, localStorage).

● lab-02: Бекенд без БД. Розробка HTTP REST API на Node.js та Express без
використання бази даних з реалізацією маршрутів та базової валідації.

● lab-03: SQLite. Підключення реляційної бази даних SQLite до бекенду, створення
схеми та виконання CRUD-запитів.

● lab-04: Інтеграція фронтенду з бекендом. Налаштування взаємодії через fetch(),
обробка CORS та керування станами інтерфейсу.

● lab-05: Уразливості і захист. Виявлення та виправлення типових вразливостей, таких
як SQL Injection, XSS, IDOR та помилки конфігурації безпеки.

Як отримати файли на свій комп'ютер

Щоб завантажити всі папки з лабораторними роботами на свій ПК для локальної роботи,
використайте систему контролю версій Git:
git clone https://github.com/myhkom-hash/Lab-1

Як використовувати лабораторні роботи

Кожна папка містить окремий етап проєкту. Щоб почати працювати з конкретною
лабораторною роботою:

1. Відкрийте термінал та перейдіть у папку потрібної лабораторної роботи (наприклад,
cd lab-2).

2. Для бекенд-частин (роботи 2-5) встановіть необхідні залежності за допомогою
пакетного менеджера npm:
npm install

3. Запустіть локальний сервер для бекенду (зазвичай на порту 3000):
npm run dev

4. Для фронтенд-частини (роботи 1 та 4) запустіть локальний веб-сервер (наприклад,
через Live Server у VS Code), щоб сторінка відкрилася на порту 5500.
